## ✦ Sobre a MABELLE

A **MABELLE** é uma marca fictícia de produtos capilares desenvolvida como projeto acadêmico, com a proposta de proporcionar uma experiência digital elegante, intuitiva e contemporânea.

Com foco em wigs, laces, cabelos humanos e acessórios capilares, a marca busca unir sofisticação, praticidade e uma apresentação visual que valorize cada produto.

Mais do que apresentar um catálogo, a proposta é transmitir uma identidade própria e criar uma experiência de navegação agradável, na qual cada detalhe contribua para a percepção da marca.

- **Conceito:** beleza, autenticidade e sofisticação.
- **Público-alvo:** pessoas interessadas em produtos capilares que valorizam a apresentação visual e uma experiência de navegação intuitiva.
- **Objetivo:** desenvolver uma landing page responsiva, com identidade visual própria, catálogo de produtos e interações no front-end.

## ✦ Jornada de desenvolvimento

### 01. O conceito inicial

O projeto nasceu da proposta acadêmica de desenvolver uma landing page para apresentar e promover uma marca fictícia.

A escolha do segmento capilar permitiu explorar uma experiência visual inspirada no universo da beleza premium. A partir dessa ideia, surgiu a MABELLE, com uma identidade elegante, moderna e coerente com os produtos apresentados.

Durante a construção, a proposta evoluiu para uma página com características de loja virtual, reunindo apresentação da marca, catálogo de produtos e elementos interativos.

- Experiência de busca e descoberta de produtos;
- Consistência entre a identidade da marca e a interface;

## ✦ Funcionalidades da MABELLE

A aplicação reúne recursos de apresentação de produtos, navegação e interação, buscando proporcionar uma experiência digital inspirada em uma loja virtual de produtos capilares.

### Funcionalidades existentes

- **Catálogo de produtos:** apresentação dos produtos capilares disponíveis.
- **Categorias de produtos:** organização dos itens por tipo.
- **Busca e filtros:** recursos para facilitar a localização dos produtos, conforme implementados na interface.
- **Produtos em destaque:** apresentação de produtos selecionados.
- **Seção sobre a marca:** apresentação da identidade e da proposta da MABELLE.
- **Depoimentos ilustrativos:** seção dedicada à apresentação de depoimentos demonstrativos.
- **Perguntas frequentes (FAQ):** informações organizadas para facilitar a navegação.
- **Carrinho ou sacola de compras:** interação com produtos e valores, conforme implementada.
- **Experiência de compra simulada:** representação de um fluxo de compra no front-end, caso disponível na versão atual.
- **Design responsivo:** adaptação da interface a diferentes tamanhos de tela, conforme validada nos dispositivos testados.

### Novas funcionalidades planejadas

#### 01. Quiz de recomendação personalizada de cabelos

O quiz será uma experiência interativa para ajudar as pessoas a encontrar produtos capilares de acordo com suas preferências.

O questionário poderá considerar características como:

- Cor desejada;
- Comprimento;
- Textura;
- Tipo de produto de interesse.

Ao final, as respostas serão utilizadas para recomendar produtos compatíveis com as preferências informadas, considerando os itens existentes no catálogo da MABELLE.

**Objetivo:** facilitar a descoberta de produtos e tornar a experiência de navegação mais personalizada.

#### 02. Lista de produtos favoritos

A lista de favoritos permitirá que as pessoas selecionem produtos de interesse e os consultem posteriormente.

A funcionalidade está planejada para incluir:

- Adicionar produtos aos favoritos;
- Remover produtos dos favoritos;
- Identificar visualmente os itens favoritados;
- Consultar os produtos em uma área dedicada;
- Manter os favoritos salvos no navegador utilizando `localStorage`.

A persistência será local ao navegador. Portanto, os favoritos não serão automaticamente sincronizados entre dispositivos ou navegadores diferentes.

**Objetivo:** facilitar a organização dos produtos de interesse e melhorar a experiência de navegação.

> **Status:** o quiz e a lista de favoritos são melhorias planejadas. Devem ser marcados como concluídos somente depois da implementação e dos testes.

## ✦ Arquitetura do projeto

O projeto busca organizar o código com separação de responsabilidades, utilizando conceitos relacionados ao padrão **MVVM (Model–View–ViewModel)**.

- **Model:** concentra os dados e as regras relacionadas ao domínio da aplicação.
- **View:** representa a interface visual apresentada ao usuário.
- **ViewModel:** organiza a lógica de apresentação e os dados utilizados pela interface.

Essa separação busca facilitar a manutenção do código, a reutilização de componentes e a evolução das funcionalidades.

A distribuição efetiva dessas responsabilidades deve corresponder à estrutura existente no código-fonte.

## ✦ Ferramentas de desenvolvimento e MCPs

Além das tecnologias utilizadas na aplicação, o processo de desenvolvimento pode contar com ferramentas que auxiliam na análise do código, no acesso a recursos externos e na validação das funcionalidades.

### O que é MCP?

O **Model Context Protocol (MCP)** é um protocolo que permite conectar ferramentas de inteligência artificial a recursos externos compatíveis, ampliando as possibilidades de interação durante o desenvolvimento.

Na MABELLE, os MCPs são considerados ferramentas de apoio ao processo de desenvolvimento e teste. Eles não precisam estar disponíveis para os visitantes utilizarem as funcionalidades do site.

### MCPs considerados para o projeto

**Playwright MCP — automação de testes no navegador**

Poderá ser utilizado para verificar o comportamento da interface no navegador, incluindo fluxos como:

- Responder ao quiz de recomendação;
- Visualizar os produtos recomendados;
- Adicionar e remover produtos dos favoritos;
- Atualizar a página e verificar a persistência dos favoritos;
- Verificar a navegação e o comportamento dos componentes.

**Figma MCP — consulta de referências visuais**

Poderá auxiliar na consulta de layouts, componentes e especificações visuais de um projeto no Figma, caso essa integração seja utilizada.

A utilização desses MCPs depende da configuração e da validação efetiva das ferramentas no ambiente de desenvolvimento. Sua inclusão nesta documentação não significa que já estejam configurados ou que os testes tenham sido executados.

## ✦ Como executar o projeto

### Pré-requisitos

- [Node.js](https://nodejs.org/)
- npm, instalado com o Node.js.

### Instalação

Clone o repositório:

```bash
git clone https://github.com/EduardaLima-09/MABELLE.git
```

Acesse a pasta do projeto:

```bash
cd MABELLE
```

Instale as dependências:

```bash
npm install
```

Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

Acesse o endereço local exibido no terminal pelo Vite.

### Build de produção

Para gerar a versão de produção, execute:

```bash
npm run build
```

O comando gera a versão otimizada da aplicação, desde que o script esteja configurado no `package.json` e que não existam erros de build.
